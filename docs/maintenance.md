# Заметки по сопровождению

## Выполненный рефакторинг типов и нейминга

Обновлено 2026-11-08. Все три пункта этого прохода выполнены.

- **Контракт изменений заметки.** В `note.model.ts` добавлен общий тип `NoteChanges`
  для частичных изменений полей `title` и `text`. Он используется в `NotesStore`,
  `LibraryFacade` и `NoteDetailComponent`. Поле `id` не входит в контракт изменений.
  Это ограничение типизации, а не проверка данных во время выполнения.
- **Получение цветов и названия.** В `SpaceRailItemComponent`, `SpaceBadgeComponent`
  и `SpaceIconPickerComponent` одно текущее CSS-значение получается из
  `SPACE_COLOR_VALUES` через `computed` с именем `colorValue`.
  В `SpaceColorPickerComponent` сохранён словарь `colorValues` для всей палитры.
  В `NotesComponent` сохранено имя `spaceColorValue`: вычисление выбирает цвет
  текущего пространства или запасной `var(--accent)`. Ссылка «Все заметки»
  использует постоянный CSS-акцент `var(--accent)`.
- **Название поля синхронизации редактора.** Поле `lastEmitted` переименовано
  в `lastSyncedValue`: оно хранит как текст, принятый через входной `value`,
  так и текст, переданный через выходной `changed`. Поведение синхронизации сохранено.

## Возможный пересмотр `.space-button`

Обсуждено 2026-11-06. Статус: наблюдение; переработка сейчас не требуется.

Файл: [`space-button.css`](../src/app/features/spaces/space-button.css).

Класс используется для ссылок в колонке пространств и вариантов выбора иконки
в форме пространства. Поведение различается: активная ссылка определяется через
`aria-current="page"`, выбранная радиокнопка — через `input:checked`.

Общее оформление намеренно сохраняет единый визуальный язык: выбор в форме
связан с тем, как пространство выглядит в приложении. Разные роли элементов
сами по себе не требуют разделения CSS.

Вернуться к решению, если оформление или состояния этих элементов начнут
развиваться независимо, появятся многочисленные исключения либо изменение
для одного места будет нарушать другое. Тогда рассмотреть сохранение общей
визуальной основы с отдельными стилями состояний навигации и выбора.
