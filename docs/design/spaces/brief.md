# Skein — пространства: бриф для макета

## Что за приложение

Skein — веб-приложение для заметок в markdown. Принцип: **закинуть мысль быстро, разложить потом**. Минимум трения, без лишних кликов и диалогов.

Десктоп, тёмная тема. Сейчас экран состоит из двух колонок:

```
┌──────────────────────┬────────────────────────────────────────────┐
│ Добавить новую заметку│                                            │
│                      │   Заголовок заметки (крупно, жирно)         │
│  Заметка 1           │                                            │
│  превью текста…   ✕  │   Текст заметки в WYSIWYG-редакторе         │
│                      │   (заголовки, списки, таблицы, код)          │
│  Заметка 2 (активна) │                                            │
│  превью текста…   ✕  │                                            │
│  …                   │                                            │
│                      │                                            │
│     ● ● ●            │                                            │
│  (выбор темы)        │                                            │
└──────────────────────┴────────────────────────────────────────────┘
```

- **Сайдбар** — отдельная скруглённая панель (`rounded-xl`) с отступом от краёв экрана, ширина ~300px, тонкая рамка. Внутри: кнопка «Добавить новую заметку», список заметок (заголовок + однострочное превью, крестик удаления, активная заметка подсвечена фоном), внизу три кружка выбора темы.
- **Справа** — открытая заметка по центру (max-width ~1024px): большой заголовок-инпут и редактор без рамок.
- Когда заметка не выбрана, справа по центру серый текст «Выберите заметку слева».
- Создание заметки — модалка с одним полем «Заголовок» и кнопками «Создать / Отмена».

Есть ещё две темы (Midnight — синеватая с циановым акцентом, Macchiato — индиговая с голубым акцентом). Макет делать в Graphite, но без жёстко прибитых цветов, кроме цветов самих пространств.

Шрифт системный, стиль сдержанный: без теней, градиентов и иллюстраций.

## Новая фича: пространства

**Пространство** — это контекст, который пользователь создаёт сам: «Работа», «Учёба», «Проект X». У пространства есть **имя, иконка (эмодзи) и цвет**. Пространств немного, обычно 3–7.

Главное: это **не теги и не папки**.
- В пространство **«входят»**: внутри видно только его заметки, и ощущается, что ты «внутри».
- Заметка хранится **один раз**, но может лежать **в нескольких пространствах** сразу.
- Есть общий вид **«Все заметки»** — все заметки без фильтра. Туда попадает и то, что закинули без пространства.

## Поведение

1. **Переключение.** Пространства видны всегда и переключаются **в один клик**, без захода в отдельный список. Активное пространство явно выделено.
2. **Внутри пространства** сайдбар показывает шапку пространства (иконка, имя, цвет) и только его заметки. Справа, как и сейчас, открытая заметка.
3. **«Все заметки»** — отдельный пункт рядом с пространствами, показывает всё.
4. **Создание заметки внутри пространства** сразу кладёт её в это пространство. Из «Всех заметок» — без пространства.
5. **Создание пространства** — модалка: имя, выбор иконки (эмодзи), выбор цвета из ~8 вариантов.
6. **Заметка в нескольких пространствах.** В шапке открытой заметки, под или рядом с заголовком, — ряд небольших «чипов» пространств, где она лежит (иконка + имя, в цвете пространства), и кнопка «+». По «+» открывается выпадающий список всех пространств с галочками.
7. **Удаление пространства** — с подтверждением. Заметки **не удаляются**: они остаются во «Всех заметках» и в других пространствах.
8. **Быстрый переход** (будущее, но место стоит предусмотреть): поиск по `Ctrl+K` по всем заметкам и пространствам.

## Что нарисовать

1. **Главный экран внутри пространства** «Работа»: переключатель пространств, шапка пространства, список его заметок, открытая заметка справа с чипами пространств.
2. **Экран «Все заметки»**, та же раскладка, но без шапки пространства.
3. **Пустое пространство** (только создано, заметок нет).
4. **Модалка создания пространства** (имя, эмодзи, цвет).
5. **Выпадающий список «+»** в шапке заметки: пространства с галочками.

## Варианты переключателя — показать оба

- **A. Узкая колонка иконок слева от сайдбара**, как серверы в Discord: кружки-иконки пространств сверху вниз, «Все заметки» отдельной иконкой сверху, «+» для нового пространства снизу. Активное — выделено цветом пространства.
- **B. Ряд иконок вверху сайдбара**, над списком заметок: «Все заметки» + иконки пространств в ряд + «+». Ниже — шапка активного пространства.
